## 任务 A：识别词表四语化 + 三条硬伤

上一轮任务书里预告的三条「会让现有实现出错」的发现，Windows 侧已全部落地并各带
「改回去就失败」的反证用例。逐条对齐，**不要自行发挥**：

1. **否定检测的位置三语不同**。中文前置、日语后置（完了して**いない**）、韩语两头都有。
   - 新增后置否定标记 + 8 字窗口，且**遇子句边界即止**——「完了。残りはない」里的
     否定说的是另一件事；
   - 韩语前置否定按 **어절（空格分词）** 判，**绝不能按字符**：真实语料里
     `이미 완료`(11265)、`제안 완료`(3261)、`잘못`(84805) 都含 안·못·미，
     按字符会把最强的肯定句全杀掉。`미` 还要求紧贴关键词且自身在词首；
   - 中文否定字集 `未没不别无非` **不要往里加日韩的字**（原因见 Windows 侧注释）。
     顺带更正上一轮任务书里的一句话：`不具合を修正完了` 我逐位验过，`不` 在索引 0、
     关键词 `修正` 在索引 4，两字符窗口**够不着**，现状不误伤——那条描述当时说过头了。
     真正会错的是反向那条（后置否定完全检测不到），已修；
   - 白名单：`問題ない` 整体是肯定评审语，不能当否定。
2. **`ClauseSeparators` 补 ASCII 句点**，但**只在句末形态**（后接空白或串尾）才算——
   否则 `v0.6.0` / `a.txt` 会把子句窗口从中间截断。向后窗口 24 → 48 迁就韩语 SOV 的
   句末谓语。
3. **兼容折叠**。见 §3.6：**不要用 `precomposedStringWithCompatibilityMapping`**，
   照搬 `TextNormalizer.FoldForMatch` 那张写死的表。理由不是洁癖：
   `String.Normalize(FormKC)` 在 `InvariantGlobalization=true` 下**静默原样返回**
   （不抛异常），而 Windows 的冒烟工程正是这个配置、主程序不是——这个坑是本轮实测
   踩出来的；且两端 ICU 版本本就不同，靠"各自调各自的 NFKC"对不齐。

另外顺手修掉的两处一直存在的匹配缺陷，mac 侧同样存在，一并做：

- **拉丁关键词要求词边界**。此前 `networking` 命中 working、`disclosed` 命中 closed、
  `prefix`/`suffix` 命中 fix——最后这条在开发语料里几乎无处不在；
- **中日同形词**：`要求`、`判断` 本想给日语 Requirement/Decision，但简体中文写法相同
  且是高频通用动词，而这两档判在 Task 之前。5189 条真实命令上量到 31 条任务被误判成
  需求，已排除；日语侧改用无碰撞的 `要件/仕様`、`決定/選定/方針`。
  反过来 `調査/検討/説明/実装/対応` 用的是日本新字体，简体写法不同，安全。

**Windows 侧的量化基线**（你落地后请在 mac 语料上做同样的对比再报）：
代号状态判定 **100% 不变**（789 处命中），类型判定 97.36% 不变（137 处变化逐条归因，
全部来自新增英日关键词或词边界修正）。

## 任务 B：69 键接线 + 设置页语言选择器

Windows 侧界面上已无任何文案字面量。mac 侧对齐时注意这几个**已经踩过的坑**：

- **落库值与显示标签必须分开**。`NodeKind` / `CodenameStatus` 落库的仍是中文 rawValue，
  过滤条件照旧下推 SQL，语言只换渲染。Windows 侧集中在 `UiText`，mac 建议同构；
- **过滤器的「全部/类型」不能直接用中文词当选项值**。它同时是选项集合成员和比较判据，
  语言一切换会连比较逻辑一起漂。Windows 改用 `::all-projects::` / `::all-kinds::`
  哨兵（冒号在路径分量里非法，真实项目名不可能相撞），显示时才映射。
  **mac 请用同一对哨兵串**，将来若要比对两端过滤状态才对得上；
- **语言即时生效 + 未保存回滚**。回滚要挂在窗口关闭上而不是「取消」按钮上——
  标题栏的关闭不走取消回调，否则界面停在新语言、设置文件却是旧值，重启又变回去；
- **语言下拉用本族语自称**（中文 / English / 日本語 / 한국어），只有「跟随系统」跟着
  翻译。界面正显示着看不懂的语言时，用户要能认出自己那一档。这四条**不进文案表**。

`design/strings.json` 本轮 Windows 侧改过一处：`dict.firstSeen` 补上了「共 N 次」的
占位（`{0} · {1}`），三份副本（design / Windows Assets / mac StringsData.swift）
已同步再生成。mac 侧本轮**只读不改**这张表，发现译文有问题请在报告里提出。
